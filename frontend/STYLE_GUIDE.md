# 前端视觉约定

用户要求：后续新增 UI 严格模仿已提供的 Figma Make 设计，保持现有布局、字体、配色与交互风格。

## 基准

- `src/app/App.tsx` 保留了导出页面的 JSX、Tailwind 类和主题参数；它是当前页面的视觉基准。
- `src/styles/theme.css` 来自设计导出。纸页、夜间、温黄、竹绿四主题必须同时适配。
- 界面操作使用设计中的 Lucide 线性图标，图标通常为 12—16px；正文阅读排版与管理控件排版分开。
- 小控件文字一般为 12px，弹窗标题为 14px。主强调色沿用铜棕 `#C17A3C`，操作区域沿用 12px/16px 圆角与细边框。

## 新增控件

管理操作优先复用 `src/components/ReaderUi.tsx`：

- `ReaderAction`：图标或图文按钮，提供可访问名称、悬停提示、焦点与禁用状态。
- `ReaderHint`：轻量说明卡片，不以高对比大色块打断阅读。
- `ReaderDialog`：与设计卡片一致的确认/管理弹窗，使用统一标题、关闭按钮、背景与动作区。

这些控件通过页面的 `--reader-*` 变量读取当前主题，不另造一套固定白底/黑字样式。配套规则在 `src/styles/integration.css`。

删除入口使用低干扰的垃圾桶图标，悬停或键盘聚焦可识别用途；确认弹窗显示目标，保留“取消”和“确认删除”。危险色仅用于危险动作的反馈，避免全页混入新的强调色。删除失败保留目标和可重试状态。

没有现成设计的功能沿用邻近控件的尺寸、留白、圆角和颜色。新需求只改必要的交互，不借机重新设计页面。完成后检查桌面、手机宽度和夜间主题。

## 当前提示语义

- TXT 重复上传会创建新副本；原书从书架打开。
- 聊天历史可能因阅读范围暂时隐藏，记录没有因此删除。
- 锁定表示暂停 AI 换曲建议，手动切歌和列表播放仍可用；实际换曲会解除旧曲目的锁定。

新增 UI 不显示 SQL、框架或内部存储字段，除非这些信息有助于用户完成当前操作。
